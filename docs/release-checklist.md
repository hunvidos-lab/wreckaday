# Release blockers — reference-photo payback direction

The current direction is ADR 0003. Earlier cloud-library and strictly device-only
plans are superseded, not silently completed.

- Ten-story live provider benchmark, identity/continuity review, measured real
  costs including failures, broader 30-variation comparison and valid-JSON rate.
- Independent image/content moderation, adversarial/prompt-injection testing,
  authorization/abuse controls and consent/age handling beyond attestation.
- Authenticated production generation, durable queue/cancellation/recovery,
  verified purchase entitlements and distributed non-resetting spending limits.
- Verified store purchases, restore/refund handling and necessary billing records
  kept separate from creative content. No checkout is connected in this preview.
- Review exact providers' commercial terms, processor retention/transfers, privacy
  and legal policies. In-memory first-party processing does not imply provider
  zero retention, GDPR compliance, anonymous delivery or untraceability.
- Physical iPhone/Android tests: import, metadata, cache cleanup, capture quality,
  accessibility, background/termination, networking and installed messaging apps.
- Current store/toolchain checks, approved brand/artwork/permanent identifiers.
- Founder approval for real spending, account connections, deployment and stores.

No configured-provider inference request, message, purchase, public deployment or
store action is performed by this revision. Do not expose the development server.
