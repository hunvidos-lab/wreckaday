# Release blockers (all pending)

- Real Supabase email OTP/magic-link round trip, refresh, logout/session revocation.
- JWKS verification, ownership/RLS review, rate limits, encrypted private storage.
- Account deletion in-app and on web, reporting, triage, retention and backup checks.
- Authorized self-photo flow, safe decoding/EXIF stripping, provider consent.
- Current commercially licensed provider evaluation, costs and ten-story benchmark.
- Live-provider pre/post moderation and manual continuity/quality review.
- Signed store receipt grants, refunds, restore and sandbox billing tests.
- Reviewed privacy/terms, processor agreements, accurate store disclosures.
- Physical iPhone + Android QA, sharing to installed messaging apps, accessibility.
- Current Apple/Google SDK and store policy checks; approved name and bundle IDs.
- Founder approval before spending, production deployment or store submission.

Gate 1 preview is not a substitute for these release gates.
